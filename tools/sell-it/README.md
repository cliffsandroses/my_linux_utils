# sell-it

- **I want to:** get rid of things I don't use, for a fair price, without effort: a scratched workout bench, speakers, a sound system, more later.
- **Where I'll use it:** phone (photos), Soma (the list), OLX (listing).
- **Done when:** each item has a priced, written listing ready to post, and is marked sold.
- **Must never:** post anything without your yes, or share your number/address in the text.

## How it works
1. You add an item: three photos, brand/model if any, what's wrong with it.
2. Deal Check's OLX search finds the going rate in Bangalore (same code as `deals-fetch`).
3. It writes the listing: title, honest condition line, price at the median minus the damage, a floor price.
4. You post it from the OLX app (OLX has no posting API); the sold price goes back into the list.
